## 一句话（最新裁决）

**不要猜怎么管理 —— 直接复刻美团一线品牌三套面：**

| ONEDAY | 美团源真相 |
| ------ | ---------- |
| 消费者 H5 | **美团 App（C 端）** |
| 员工 / 商户移动 H5 | **美团商家端 App** |
| 老板管理 PC | **美团商家端 PC** |
| 平台 / 渠道 PC | **美团平台端 / 代理 PC** |

**唯一单独定制：工作流整合页。**  
施工权威表：`MEITUAN_PC_H5_PARITY_INVENTORY.md`（对表逐页，禁止自创管理 IA）。

默认品牌色用 **美团黄**（不锁企微蓝）；全部走 **design tokens**，以后换肤只改 token，不改业务页。

## UI 总原则

| 项 | 裁决 |
| -- | ---- |
| 高保真视觉 | **与美团 PC / H5 一模一样** |
| 信息架构 / 交互 / 功能链路 | **与美团一模一样** |
| 默认色 | **美团黄**（`--od-brand-*`） |
| 企微蓝 | **不锁死**；需要时只换 token 主题包 |
| 换肤 | 只改 `packages/design-tokens`（+ 可选 `data-theme`）；禁止页级 hex 堆叠 |
| 开发节奏 | **宁快**：先按美团页同构落地，少纠结色板 |

## 轨 A — 工作流整合页（唯一定制）

- 入口可挂在美团同构导航的合理位置，但 **页内能力、布局、字段以 ONEDAY 工作流整合为准**。
- 不要求该页像素级仿美团（美团无等价「工作流整合」则按 ONEDAY 产品定义做）。
- 其余所有已存在的管理/员工/消费者页，整改目标均为美团对应页，而不是「美团壳 + 自创内容块」。
