## 一句话

**UI / 细节 / 架构 / 交互 / 功能链路管理：100% 复刻美团。**  
默认品牌色用 **美团黄**（不锁企微蓝）；全部走 **design tokens**，以后换肤只改 token，不改业务页。

差异仍保留在：**可 DIY 的经营内容与工作流配置**（模板/模块/品牌配置），不是另造一套陌生后台皮肤。

---

## UI 总原则（最高优先级）

| 项 | 裁决 |
| -- | ---- |
| 高保真视觉 | **100% 对标美团**（商家端 / 相关管理面） |
| 信息架构 / 交互 / 功能链路 | **100% 对标美团** 成熟链路 |
| 默认色 | **美团黄**（`--od-brand-*`） |
| 企微蓝 | **不锁死**；需要时只换 token 主题包 |
| 换肤 | 只改 `packages/design-tokens`（+ 可选 `data-theme`）；禁止页级 hex 堆叠 |
| 开发节奏 | **宁快**：先美团黄默认上线，少纠结色板 |
