## R. 一次性整改建议（仅 P0–P3）

### P0 — 产品定位错误 / 真人阻塞

1. **修复 3203/3204 Next 静态资源 403**（或改用可水合的生产 build 服务），使老板/平台登录页可交互。否则后续 UI 整改无法真人验收。

3. **统一 outbound：** 一律经 `/c/actions` 确认留痕后再跳转。
   - 归类：**A**

### P1 — 真人商用测试前必须修

1. Management **外部入口配置页**（美团/抖音/通用 https）。
2. 门店 **电话 + 导航 + 营业时间文本 + 1 张封面**。

## COMMERCIAL-UI-ALIGNMENT（给 Codex 的批量施工方案）

**原则：** 还原已定产品设计到 UI 与真人链路；不是重新开发 ONEDAY。

### Batch 0 — 试点可测性（阻塞解除）

- 修复 Management/Platform 本地静态资源加载，保证 `/login` 可提交、dashboard 可渲染。
- 验收：Playwright 老板登录→`/m/dashboard` 非「正在恢复安全会话」。

### Batch 1 — 经营入口对齐（P0+P1 核心）

- 外链配置 UI + seed 两条平台 link
- 门店电话/导航/封面/营业时间
- 团购卡 + `/c/actions` 统一
- `action_grid` 可点绑定或去伪
- 员工真底栏 + 中文任务文案
- 对应 Playwright 商业旅程

### Batch 2 — 壳与千店千面最小集（P2）

- 宫格启动器、四端壳、装修最小编辑、坐标治理

### 明确禁止

- 支付、自研商城、ERP、OA、自动外发、假 AI、大规模无关重构、为测通改断言放水

### 建议验收门槛（对齐后才可称接近商用）

1. 消费者不读文档能完成：发现→进店→打电话/导航/点开美团或抖音模拟链。
2. 员工不找 URL 能完成：工作台→任务→跟进→完成。
3. 老板能登录经营台看到该客户来源与动作。
4. 平台/渠道账号能打开仪表盘。
5. 非法外链仍被拒；不出现“已发送到美团”无回执文案。
