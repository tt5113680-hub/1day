# 测试策略

## 单元测试

领域规则、权限判断、状态机、归因算法、标签置信度、AI动作治理。

## 集成测试

数据库、Redis、队列、Outbox、工作流、连接器模拟、文件证据、通知。

## 契约测试

前后端共享 Schema、外部连接器适配器、Webhook。

## E2E 主链路

- 扫码 → 浏览 → 外部动作 → 员工提醒 → 证据提交 → 管理看板；
- 新客留资 → 分配 → 跟进 → 成交 → 复购任务；
- 商圈进入 → 商户浏览 → 渠道归因；
- 商户开通 → 员工创建 → 权限配置；
- 角色越权和跨租户访问必须失败。

## 视觉回归

固定视口、固定种子数据、屏蔽动态时间、截图差异阈值和人工抽检。
