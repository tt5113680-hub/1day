# 归因与证据模型

## 归因维度

- first_source：首次来源
- current_source：当前访问来源
- final_source：成交前最后来源
- scene_code：场景码
- channel：渠道
- business_circle：固定商圈
- employee：分享/接待/跟进员工
- content：内容或活动
- external_platform：外部平台

## 贡献角色

- referrer：推荐人
- receiver：接待人
- owner：客户责任人
- closer：成交人
- verifier：核销/结果确认人

## 证据等级

1. 官方连接器回写；
2. 平台订单号或核销码；
3. 截图/照片；
4. 员工人工声明；
5. 行为推断。

报表必须区分“已确认结果”和“推断结果”，不得混为一谈。
