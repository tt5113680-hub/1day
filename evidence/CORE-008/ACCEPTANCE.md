# CORE-008 验收证据

- 交付多租户页面模板、版本和模块实例模型；草稿预览返回真实模块配置，发布通过已发布版本指针切换，回滚可恢复任一历史版本。
- 创建模板使用 Idempotency-Key；发布/回滚使用模板版本乐观锁；模板写操作均写入审计和带 correlation/trace 的 Outbox 事件。
- `tests/core-008-e2e.test.mjs` 在构建后的 NestJS/Fastify API 与 PostgreSQL 上验证草稿、预览、发布、版本复制和回滚，以及未登录与跨租户拒绝。
- 本任务提供模板数据与预览 API；后续各角色页面任务消费该能力实现端侧可视化装修。无第三方服务依赖。
