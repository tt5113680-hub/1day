# CORE-010 验收证据

- 交付租户隔离的工作流定义、版本、发布、实例、步骤、条件、任务与审批持久化模型；发布版本不可被后续草稿替代，实例固定使用当时的已发布版本。
- 启动实例会按上下文评估等值条件：适用步骤被激活，不适用步骤标为跳过；任务步骤创建真实 `tasks` 记录，审批步骤仅能由受指派的在职员工推进；拒绝和超时均终止实例。
- 所有配置、实例和状态变更经 TenantContext/RBAC/乐观锁或幂等键保护，并写入审计日志与携带 correlation/trace 的 Outbox 事件。
- `tests/core-010-e2e.test.mjs` 在构建后的 NestJS/Fastify API 和 PostgreSQL 上验证定义幂等、版本发布、条件、任务生成、审批、超时、审计/Outbox、校验失败、未登录、无权限和跨租户拒绝。
- 本任务没有端侧页面或第三方服务调用，页面 E2E/截图、可访问性和外部服务失败场景不适用。
