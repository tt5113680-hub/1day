# 商业 MVP 范围

## 必须交付

- 统一消费者经营入口；
- 租户、组织、门店、员工、角色、权限；
- 消费者、员工、管理、平台/渠道四类界面；
- LBS 附近商户与固定商圈两套发现模型；
- 页面模板与模块化装修，支持实时预览；
- 外部平台入口、链接、小程序路径、抖音/美团等动作配置；
- 订单号、截图、核销码、人工确认等结果回收；
- 客户主档、来源、归属、行为、跟进、成交、复购；
- 员工任务、提醒、超时、异常升级；
- 管理看板、漏斗、归因、员工过程和权限审计；
- 一级渠道/代理、商户开通、固定商圈；
- AI 消费者推荐、员工行动建议、老板经营建议、渠道运营建议；
- 事件、证据、审计、多租户和权限；
- 完整测试、部署、监控和备份恢复。

## 本阶段明确不做

- 完整自研商城、支付、收银；
- 完整外呼系统；
- 完整 OA/ERP/传统 CRM 替代；
- 多级代理分润、提现、发票；
- 完整 OEM 白标和私有化部署；
- 开放式第三方插件市场；
- 任意代码级低代码平台；
- 复杂财务结算；
- 大量行业模板；
- 未经真实 API 授权的自动私聊、自动发朋友圈或自动平台发布。

## MVP 成功判断

不是“页面数量够多”，而是以下闭环可真实演示：

1. 消费者通过场景码进入商户页并执行动作；
2. 系统记录来源、场景、员工、商户和行为；
3. 未完成动作自动形成员工任务；
4. 员工能完成跟进并上传证据；
5. 管理者能看到过程、异常、归因和结果；
6. AI 能给出可执行建议，并通过权限确认后落地；
7. 渠道/商圈能开通商户并查看运营情况。
