# ONEDAY V3.0 唯一极细施工包

版本日期：2026-08-05

## 这次为什么重新生成

旧工程同时叠加 Cursor Agent、Headless、Codex、自动调度和多轮权限确认，已经破坏了“单一执行路径、可验证、可恢复”的基本原则。本包不继续修补旧流程，而是重新冻结产品、工程和交付规则。

## 唯一执行路线

- **唯一写代码工具：Cursor 内的 Codex。**
- 不使用 Cursor Agent 写代码。
- 不使用 Cursor Headless。
- 不运行无人值守总控脚本。
- 不允许两个代理同时修改仓库。
- 不复用 `D:\1DAY_V2` 作为新工程目录。
- 新代码工程固定为：`D:\ONEDAY_V3`。
- 本施工包固定为：`D:\ONEDAY_V3_PACKAGE`。

## 用户只需要做的事情

1. 将本包解压到 `D:\ONEDAY_V3_PACKAGE`。
2. 用 Cursor 打开该文件夹。
3. 打开 Cursor 内 Codex，新会话粘贴 `00_START/CODEX_START_HERE.txt` 全文。

之后 Codex 先创建新仓库，再按任务索引施工。旧工程只作为参考证据，不自动迁移、不覆盖、不删除。

## 成功标准

- 产品边界不再反复变化。
- 每个任务都拥有独立施工包、验收项和测试门槛。
- 没有测试证据不得标记 PASS。
- 每完成一个任务必须提交 Git 并更新状态文件。
- 任何不明确的产品问题先记录为决策项，不允许代理自行扩张产品范围。
