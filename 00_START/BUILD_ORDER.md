# 总施工顺序

## 阶段 0：新仓库与工程底座

建立新仓库、Monorepo、数据库、鉴权、多租户、事件总线、设计系统、测试框架和状态机制。

## 阶段 1：平台公共底座

完成租户、组织、账号、角色、权限、门店、渠道、插件入口、页面模板、审计日志等公共能力。

## 阶段 2：消费者端闭环

完成统一入口、发现、商户/服务详情、外部动作、留资、订单/截图/核销结果回收和过程查询。

## 阶段 3：员工端闭环

完成工作台、任务、客户、跟进、分享码、获客池、养客、通知和个人工具。

## 阶段 4：管理端闭环

完成经营看板、漏斗、客户、流程、AI建议、门店、员工、角色权限、审计、绩效过程、归因、内容、装修和连接器。

## 阶段 5：渠道与固定商圈

完成一级渠道、商户开通、固定商圈、商圈商户和运营数据。

## 阶段 6：商业 MVP 加固

完成安全、性能、可观测性、备份恢复、E2E、视觉回归、试点数据和发布验收。

任何阶段不得跳过前置基础。具体任务顺序以 `08_TASKS/TASK_INDEX.md` 为唯一依据。
