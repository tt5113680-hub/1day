# 商业演示场景

## 场景一：餐饮门店桌码

消费者扫桌码进入统一页 → 查看推荐套餐 → 跳转美团/抖音或自营入口 → 2分钟未完成触发员工提醒 → 员工协助 → 上传订单号/截图 → 管理端确认来源、接待、成交和核销贡献。

## 场景二：企业服务销售

客户从员工分享页留资 → 自动归属员工 → 生成跟进任务 → 员工记录沟通并生成下次提醒 → 主管查看逾期和指导 → 成交/收款 → AI 生成复购或转介绍任务。

## 场景三：固定商圈

银行/保险/社区建立固定商圈 → 邀请商户并经平台审批 → 消费者从商圈页发现权益和商户 → 来源保留为商圈 → 渠道查看流量、商户活跃和续费机会。

## 场景四：商户快速开通

一级渠道录入商户 → 选择行业模板 → 创建管理员和门店 → 配置入口插件 → 商户登录看到初始化工作台 → 平台和渠道均能查看交付进度。
